# Danmaku for iPhone and iPad

Native SwiftUI trusted-LAN client, iOS/iPadOS 17 or later. Open
`Danmaku.xcworkspace` after dependency installation. The committed project and
shared Danmaku scheme include the application, Swift core, and application tests.

## Setup

Install Xcode with the iOS SDK, a supported Ruby (3.2 or newer), Bundler,
CocoaPods tooling from the locked Gemfile, PowerShell, and ffmpeg for tests:

```powershell
cd apps/ios
bundle install
bundle exec pod install --deployment
cd ../..
./tools/macos/build-ios.ps1 -Platform Device
./tools/macos/build-ios.ps1 -Platform Simulator
```

MobileVLCKit 3.7.2 is locked in Podfile.lock; generated Pods, downloaded media
frameworks, fixtures, and build products are ignored. Application artwork is
generated from `tools/make-icon.swift`. If target membership changes, regenerate
the project with `bundle exec ruby tools/generate-project.rb`, then run pod install.

## Tests

```powershell
xcrun simctl list devices available
./tools/macos/test-ios.ps1 -SimulatorId <simulator-uuid>
```

The core tests consume the canonical Rust LAN and Android domain fixtures.
Application tests use synthetic MP4/MKV, two AAC audio tracks, SRT, and ASS
generated by ffmpeg into `build/ios-fixtures`; no real library is needed. The
test command may start the selected iOS simulator, but does not open the
Simulator GUI or capture screenshots. Physical-device, real-library, live-account,
and visual layout QA remain separate checks.

## Install on a connected iPad or iPhone

Sign into your Apple account in Xcode Settings and select its Personal Team.
Enable Settings → Privacy & Security → Developer Mode on the device, restart,
and confirm. Keep the device paired, unlocked, and trusted. Find its identifier
with `xcrun devicectl list devices` and the team identifier in Xcode signing settings.

```powershell
./tools/macos/deploy-ios.ps1 -TeamId <team-id> -DeviceId <device-identifier> -FixturePlayback
```

The command signs, installs, and launches the app. `-FixturePlayback` copies only
generated synthetic media to Documents/Fixture, verifies MP4 and MKV playback
with two audio tracks and sidecar subtitles, and saves device reports under
`build/`. The Debug-only fixture launch uses isolated state and skips saved server connections. Omit
this flag for normal launch. It never uninstalls an existing
copy. Reinstall using the same bundle ID and team to preserve saved connections,
downloads, preferences, and progress. Free Personal Team provisioning expires
after seven days; rebuild and reinstall to renew it. Signing accounts, private
keys, team selection, and provisioning profiles are not committed.

## Connections and offline behavior

The server advertises `_danmaku._tcp.local.` alongside Android UDP discovery.
Allow Local Network access when prompted. Older server installations can be
connected manually at `http://<LAN-address>:8686`; upgrade the server for Bonjour
discovery and native background download resume validators. HTTP remains trusted
LAN only and provider credentials stay on the server.

Downloads contain an explicit episode/series/folder snapshot; folders are not
watched for new files. Background transfers use Wi-Fi and iOS scheduling.
Force-quitting prevents automatic background relaunch until the app is opened.
Native resume data is persisted when available; if iOS no longer retains the
partial transfer, retry starts that asset again. Missing optional subtitles or
posters do not prevent video playback. A playing cache cannot be deleted.

Progress checkpoints live outside the cache manifest. Reconnect uploads only
newer checkpoints for that server and preserves newer server progress. Tracking
sync always submits the exact reviewed preview; a 409 requires a fresh review.
Account setup, mapping, and provider-ahead conflict import use server/web admin.

App Store/TestFlight distribution, Apple TV, Picture in Picture, AirPlay, and
Android-style self-updates are not part of this initial client.

Reference behavior: [Apple background downloads](https://developer.apple.com/documentation/foundation/downloading-files-in-the-background),
[Personal Team limits](https://developer.apple.com/help/account/basics/about-your-developer-account),
and [VideoLAN release manifest](https://raw.githubusercontent.com/videolan/vlckit/master/Packaging/MobileVLCKit.json).
